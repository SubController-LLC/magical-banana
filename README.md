# マジカルバナナ — 説明できればセーフ

スマホ1台を回して遊ぶ日本語パーティーゲーム。2〜12人、5 / 8 / 10 / 15 / 20秒を選べます。別端末間の同時対戦・同期はありません。

## 遊び方

1. 名前を1行に1人、最初のお題、制限時間を入力。
2. 連想した言葉を入力、または「声で答える」で録音・文字起こし。「つなぐ」で次の人へ。
3. AIはバックグラウンドで「セーフ / 説明要求 / 判定不能」を返します。説明要求で進行や時計は止まりません。
4. 一時停止・タイムアウト・終了後に審議。マイクまたは文字で説明を保存し、AIの参考意見を聞けます。
5. 参加者が「セーフにする / アウトにする」で最終決定。AIがアウト寄りでも参加者はセーフにできます。
6. 「あそんだ記録」で履歴と録音を再生。判定を変更すると負け数も再計算されます。

タイムアウトは即座に負け+1（同じイベントを二重加算しません）。説明要求・判定不能・未審議・AIの再評価だけでは加算しません。未審議は保持し、再開できます。

## ローカル開発

Node.js 22.13以上（推奨24）。

```sh
npm ci
cp .env.example .env.local
# .env.local を自分のエディタで設定。秘密値はコミットしない。
npm run dev
npm test
npm run build
```

http://127.0.0.1:5178 でフロントとAPIが同時に動作します。

## AI接続

Vercelのサーバー環境変数に以下を設定します。クライアントへAPIキーを渡しません。

- `OPENAI_API_KEY`: OpenAI APIキー
- `OPENAI_MODEL`: モデルID（初期値 `gpt-4.1-mini`）
- `AI_ENABLED`: `true` で有効
- `JUDGE_ACCESS_CODE`: 参加者に伝えるランダムな合言葉

ゲーム開始画面でAI審判を有効化し、合言葉を入力します。合言葉はReactのメモリにのみ保持します。ページを再読み込みすると再入力が必要です。AI未接続・上限・ネットワークエラー時は「判定不能」にして人間の審議に残します。

AIには文字のみを送り、個人的経験の真偽の証明を要求しません。筋道・経験・ユーモア・単なる羅列ではないことを評価します。AI SDKの構造化出力で検証し、Responses APIでは `store: false`。再試行なし、14秒上限、最大400出力トークン。合言葉認証とインスタンス単位40リクエスト/分の補助的制限があります（分散全体の課金上限ではありません）。プロバイダーの利用制限も設定してください。

## 録音・保存とブラウザ

- `getUserMedia` + `MediaRecorder` で音声を録音し、IndexedDBに保存します。サーバーへ録音ファイルは送信しません。
- Web Speech APIの日本語文字起こしを利用します。ブラウザにより提供元の音声認識サービスへ音声が送信されます。非対応・権限拒否・認識不良でも文字入力を利用できます。
- 説明音声は録音を停止した後、文字を確認・修正して保存します。
- 文字起こしに失敗したときは「審議待ちで次へ」で、負けを付けずに次の人へ進めます。次の人のお題は最後に認識できた言葉を維持します。
- マイクはHTTPSまたはlocalhostが必要です。実機のChrome/Safari等で権限と音声認識対応を確認してください。
- ゲーム状態・音声・元のAI判定・説明・再判定・最終判定は同じ端末の同じブラウザに残ります。ブラウザデータ削除で消えます。複数端末への同期・クラウドバックアップはありません。
- 画面がバックグラウンドになると自動一時停止。再読み込みしたゲームも停止状態で復元します。中断されたAI判定は「判定不能」として審議可能な状態を保ちます。
